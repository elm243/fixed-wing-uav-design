# High-Altitude Fixed-Wing UAV Project

## Overview

This project focuses on the conceptual design and development of a reusable electric fixed-wing UAV intended for high-altitude operation, extended endurance, and modular payload capability.

The aircraft is being developed through a structured aerospace design process including mission definition, requirements development, configuration trade studies, preliminary sizing, aerodynamic analysis, propulsion sizing, and eventual simulation and flight testing.

## Primary Design Goals

- 15,000 ft design altitude
- 90-minute baseline mission endurance
- Approximately 30 minutes of loiter capability
- Modular payload capability up to 1.0 kg
- Reusable and recoverable airframe
- Electric propulsion
- Manual flight capability with future autonomous operation

## Current Status

The project is currently in the conceptual design phase.

A weighted aircraft configuration trade study was completed comparing seven candidate configurations. The **High-Wing Conventional Pusher** configuration was selected as the current baseline design.
